# Totem — implementação inicial

Três estados: seleção, senha emitida e comprovante pronto para impressão. Responsivo para tablet, desktop e totem, com CSS para impressão. QR Code aponta para `/acompanhar/demo` **apenas em ambiente de demonstração**. Os números C024, CP008, P016 e PP003 são exemplos fixos: não representam filas reais nem são exclusivos. Não há API de filas, geração de token seguro, reserva de senha, comunicação com impressora térmica ou logotipo original em arquivo. A marca no cabeçalho é uma aproximação temporária em CSS até recebermos o asset da logo. A ação imprimir abre a janela de impressão do navegador; não garante impressão automática nem papel térmico. Antes de uso real, implementar backend transacional, tokens de acompanhamento seguros, política de prioridade e integração de impressora.
